# SoilSense 🌱

## An IoT-Driven Machine Learning Framework for Soil Fertility Classification and Counterfactual Fertilizer Recommendation

### Project Overview
SoilSense is an IoT and Machine Learning based project that classifies soil fertility into Low, Medium, and High categories and provides fertilizer recommendations.

### Objectives
- Monitor soil parameters.
- Predict soil fertility using Machine Learning.
- Compare different ML algorithms.
- Generate irrigation and nitrogen alerts.
- Provide fertilizer recommendations.

### Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- IoT Sensors

### Machine Learning Algorithms
1. Decision Tree
2. KNN
3. SVM
4. Random Forest
5. Gradient Boosting

### Project Files
- soilsense.ipynb – Python notebook
- SoilSense_Report.pdf – Project report

### Results
Gradient Boosting achieved a Macro-F1 score of 0.743 using simulated soil sensor data.

### Project Status
Prototype developed and tested using simulated IoT soil sensor data.
